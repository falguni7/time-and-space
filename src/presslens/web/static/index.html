  1. Tracking → metrics. For every pass: pressure on the passer (nearest defender, 1 = within 1 m), every passing option's chance of arriving (xPass) and value, the decision gap (best minus chosen), and the change in expected threat (xT).
  2. Moment cards. Code picks the moments: press traps, presses broken, better passes missed, goals.
  3. Fact sheet. Code, not a model, writes what may be said, including how the pass compares with the league in the same third under the same pressure.
  4. Agents. Explainer writes a neutral text; a rule-based Verifier checks every number and name; a Critic agent checks the meaning; Persona agents rewrite it for each viewer and language, and are checked again. Two failures → a safe fallback is shown instead.
  5. Relevance. A selector builds each viewer's feed (club, player, kind of viewer) and says why.
  6. Analyst. Answers league questions by querying the metrics cube through MCP tools, with sample sizes and confidence intervals.
